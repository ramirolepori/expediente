# 0009. Audio: una sola pista para todos

**Contexto.** Se juega en el mismo lugar. Si cada dispositivo reproduce la voz, suena con eco.

**Decisión.** Una sola pista de audio: la reproduce la tele o un dispositivo elegido. Voces candidatas: Piper en la PC anfitriona (gratis, sin cuota).

**Consecuencias.** Sin implementar. Hace falta definir quién reproduce y una tecla de pulsar para hablar (accesibilidad).
