# 0008. Los casos viven en el repo público

**Contexto.** El repo es público por el plan gratis de Actions, y los `caso.json` incluyen la solución.

**Decisión.** Se acepta: es un juego entre amigos. Las soluciones nunca viajan al navegador durante la partida (0001), pero se pueden leer en GitHub.

**Consecuencias.** Revisable: si hace falta, mover los casos a Supabase y cargarlos del lado del servidor.
